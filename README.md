# 📺 Immortal Video Streamer (MissAV Ultimate)

> **"Experience Uninterrupted Streaming. Videos will play forever, even if you're not looking."**
> *(ประสบการณ์การรับชมที่ไร้รอยต่อ วิดีโอจะเล่นต่อไปตลอดกาล แม้ว่าคุณจะไม่ได้มองอยู่ก็ตาม)*

This script is a powerful tool designed to bypass "Auto-Pause" and "Page Visibility" restrictions on video streaming sites.

---

## 🚀 Key Powers / ความสามารถหลัก

*   **🛡️ Anti-Pause:** Blocks the website's ability to call `.pause()`. You control the stop, not the site.
    *(บล็อกคำสั่งหยุดวิดีโอจากตัวเว็บ คุณคือคนเดียวที่มีสิทธิ์สั่งหยุด)*
*   **👁️ Immortal Visibility:** Tricks the browser into thinking the tab is always visible and focused.
    *(หลอกเบราว์เซอร์ว่า Tab นี้ถูกเปิดจ้องไว้ตลอดเวลา)*
*   **⚡ Zero-Downtime Re-Play:** If anything interrupts the video, it restarts in 250ms.
    *(หากวิดีโอหยุดด้วยเหตุสุดวิสัย ระบบจะสั่งเล่นใหม่ทันทีภายใน 0.25 วินาที)*
*   **💤 Anti-Throttling:** Prevents the browser from putting the tab to sleep.
    *(ป้องกันไม่ให้เบราว์เซอร์สั่งลดการทำงานของ Tab ขณะที่คุณไปทำอย่างอื่น)*
